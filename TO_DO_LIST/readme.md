# 📝 To-Do List Web App  

A simple, interactive To-Do List application built with **HTML, CSS, and JavaScript**. This app allows users to add, check off, and remove tasks while saving their progress using **localStorage**.  

## 🚀 Features  
- 📌 **Add Tasks**: Enter a task and click "Add work" to add it to the list.  
- ✅ **Mark Tasks as Completed**: Click on a task to toggle between completed (crossed out) and active.  
- ❌ **Remove Tasks**: Click the "×" button next to a task to remove it.  
- 💾 **Persistent Storage**: Tasks are saved in **localStorage**, so they remain after a page refresh.  
- 📱 **Responsive Design**: Works on both desktop and mobile devices.  

## 🛠️ Technologies Used  
- **HTML**: Structure of the app  
- **CSS**: Styling with gradients, shadows, and responsive design  
- **JavaScript**: Dynamic task management with event handling
